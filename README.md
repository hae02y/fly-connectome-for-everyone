# 처음 만나는 초파리 뇌: 커넥톰과 뇌-inspired AI

초파리의 작은 뇌를 통해 뉴런, 시냅스, 커넥톰, 뇌 시뮬레이션과 뇌-inspired AI를 비개발자도 이해할 수 있게 설명하는 과학·기술 교양서입니다.

## 집필 원칙

- 공식 연구기관과 논문을 우선 출처로 사용합니다.
- 실제 연구 이미지와 생성 도식을 구분합니다.
- 실제 이미지에는 출처, 원문 링크, 라이선스를 함께 기록합니다.
- 커넥톰(연결 지도)과 기능적 뇌 시뮬레이션을 혼동하지 않습니다.
- “디지털 초파리”를 의식이나 생명체의 복제로 과장하지 않습니다.
