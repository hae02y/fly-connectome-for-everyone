# 처음 만나는 초파리 뇌: 커넥톰과 뇌에서 배우는 AI

비개발자를 위한 초파리 신경계·커넥톰·계산 모델 입문서입니다. 구조와 기능의 차이부터 실제 데이터 탐색, 가상 몸과 로봇, 연구 뉴스 읽기까지 사례와 표로 설명합니다.

## 원고 상태

- 자료 확인 기준: 2026년 10월 23일
- 00~18장 전체 원고 작성
- 각 장에 서로 다른 이미지 1개: 실제 연구 렌더링 9개, 저자 제작 도식 10개
- 실제 이미지의 제작자·원본·CC BY 4.0·변경 여부를 본문에 표기
- 16장 브라우저 탐색 실습, 18장 용어표·워크북 수록
- 10·16장에 커넥톰 소스코드 다운로드·Conda·Jupyter·연결표 분석 따라하기 추가
- 대규모 뇌 모델의 직접 실행 검증 및 로그인 이후 UI 실습은 미실시
- 위키독스: [처음 만나는 초파리 뇌](https://wikidocs.net/book/21794)
- GitHub 저장소와 연결하여 원고를 관리합니다.
