# 이미지 출처 및 사용 기록

이 책의 이미지는 두 종류로 관리합니다.

1. **참고 이미지**: 연구기관·논문·공식 데이터베이스가 공개한 실제 시각 자료. 원문 URL과 라이선스를 기록합니다.
2. **설명 도식**: 책의 이해를 돕기 위해 직접 제작하거나 생성한 이미지. 생성 이미지임을 표시합니다.
