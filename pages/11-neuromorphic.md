# 11. 뇌에서 배우는 AI와 뉴로모픽 컴퓨팅


초파리 뇌 연구를 접하면 “이 구조를 복사하면 더 좋은 AI가 되는가?”라는 질문이 자연스럽게 나옵니다. 답을 찾으려면 무엇을 가져오는지 먼저 정해야 합니다. 연결 형태를 가져오는 것, 학습 규칙을 참고하는 것, 계산 장치를 바꾸는 것은 서로 다른 선택입니다.

## 뇌를 참고하는 세 수준

| 수준 | 아이디어 | 평가 기준 |
|---|---|---|
| 구조 | 연결의 희소성·반복 회로 참고 | 같은 자원에서 성능이 좋아지는가 |
| 알고리즘 | 시간에 따른 신호와 학습 규칙 참고 | 새로운 조건에 잘 적응하는가 |
| 하드웨어 | 사건 중심으로 계산하는 장치 | 지연·전력·전체 비용이 줄어드는가 |

스파이킹 신경망은 시간 속에서 발생하는 신호를 계산의 중요한 요소로 사용합니다. 뉴로모픽 장치는 이런 방식의 계산을 효율적으로 지원하려는 접근 중 하나입니다. 스파이킹 모델을 일반 컴퓨터에서 돌릴 수도 있으므로 두 용어가 같은 뜻은 아닙니다.

## 왜 적은 계산이 매력적인가

배터리로 움직이는 작은 로봇은 큰 서버를 항상 사용할 수 없습니다. 필요한 순간에 필요한 정보만 처리하면 유리할 수 있습니다. 하지만 이론상 계산이 적다는 사실과 완성된 시스템의 전력 소비가 낮다는 사실은 별도로 측정해야 합니다.

센서가 많은 전력을 쓰거나 데이터 변환이 무거우면 신경망 내부의 절약 효과가 줄어듭니다. 비교표에는 모델 계산뿐 아니라 센서, 전송, 메모리, 출력 장치의 비용도 포함해야 합니다.

## 공정한 비교의 예

가상의 장애물 회피 과제에서 모델 A가 95% 성공하고 모델 B가 90% 성공했다고 해봅시다. A가 열 배 느리다면 작은 비행체에는 적합하지 않을 수 있습니다. 반대로 B가 빠르더라도 조명이 바뀌자 급격히 실패한다면 현장 사용에 문제가 있습니다.

| 측정 | 함께 적을 조건 |
|---|---|
| 성공률 | 장애물 유형·시험 횟수 |
| 응답 시간 | 하드웨어·입력 크기 |
| 에너지 | 측정 범위·대기 시간 포함 여부 |
| 안정성 | 잡음·빛·환경 변화 |
| 학습 비용 | 데이터 수·훈련 시간 |

이 예시의 수치는 실제 제품 평가가 아닙니다. 좋은 기술 이름보다 비교 조건을 먼저 보는 연습입니다.

## 희소한 연결을 왜 살펴볼까

모든 처리 단위를 서로 연결하면 연결 수가 빠르게 늘어납니다. 필요한 통로를 선택하면 저장 공간이나 계산을 줄일 여지가 있습니다. 하지만 적게 연결했다고 자동으로 좋은 모델이 되는 것은 아닙니다. 필요한 정보의 경로까지 끊으면 성능이 낮아질 수 있습니다.

작은 사무실에서 모든 사람이 모든 메시지를 받게 하는 경우와 담당자에게만 전달하는 경우를 비교해 보세요. 전달량은 줄어도 담당자를 잘못 정하면 일이 막힙니다. 뇌에서 영감을 얻은 연결을 평가할 때도 효율과 정보 손실을 함께 봐야 합니다.

## 제품 소개문을 읽는 연습

“뇌를 닮아 전력을 크게 절약한다”라는 문장에서 최소한 두 질문을 꺼내 보세요. 무엇을 닮았는지, 무엇과 비교해 얼마나 절약했는지입니다. 측정 조건이 없다면 가능성 소개로 읽고 검증된 수치로 재사용하지 않습니다.

특히 생물의 소비 에너지와 컴퓨터 프로그램의 소비 전력을 그대로 비교하려면 측정 경계가 일치하는지 검토해야 합니다. 뇌만의 계산 비용과 센서·통신·저장장치까지 포함한 시스템 비용을 섞으면 비교가 불공정해집니다.


## 연구 단계의 가능성을 읽는다

커넥톰을 사용한 모델이 성공했다면 생물학적 연결이 얼마나 기여했는지도 확인해야 합니다. 같은 크기의 무작위 연결, 단순한 기존 제어기와 비교하면 도움이 됩니다. 실제 연결을 섞었는데 성능이 그대로라면 “뇌 배선 덕분”이라는 설명은 약해집니다.
